# printer — תרגול SQL ופייתון

משחק תרגול בעברית (RTL) ל-SQL (סגנון MySQL) ולפייתון. רץ בדפדפן, מותאם לאייפון, ואפשר להוסיף למסך הבית.

**כתובת חיה:** https://roeibayde23.github.io/printer/

## הרצה מקומית

צריך שרת HTTP (קובץ WASM לא נטען מ-`file://`):

```bash
python3 -m http.server 8765
```

ואז לפתוח: http://127.0.0.1:8765/

## הערות

- **SQL** רץ במכשיר עם sql.js (SQLite WASM). `LIMIT` עובד כמו ב-MySQL; `TOP` הוא תחביר של SQL Server ולא רץ כאן.
- **פייתון** (שאלות «כתבו קוד») טוען את Pyodide מ-CDN בפעם הראשונה (~30MB, דורש אינטרנט). שאר שאלות הפייתון עובדות גם בלי זה.
- התקדמות, XP ורצף נשמרים ב-`localStorage` בלבד.
